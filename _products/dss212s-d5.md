<ul>
<li>Storage server supports Dual Intel® Xeon® SP Skylake up to 2TB DDR4</li>
<li>2U with 12x 3.5” 12Gbps SAS hot-swap HDD bays</li>
<li>Five 40mm fan modules per motherboard module</li>
<li>Support two hot-swap MB Modules each with Xeon DP server boards in one system as unified redundant controllers</li>
<li>HA Redundant Cluster-in-a-Box solution with PCIe NTB and GbE heartbeat</li>
