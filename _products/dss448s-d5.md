<h2>Key Features:</h2>
<ul>
<li>HA Redundant Storage server support Dual Intel® Xeon® SP Skylake / Cascade Lake up to 1TB DDR4</li>
<li>4U with 48x 3.5” 12Gb/s dual-ported SAS hot-swap HDD bays</li>
<li>Four 60mm fan modules for each motherboard node</li>
<li>Support two hot-swap motherboard nodes; each with Xeon DP server boards in one system as unified redundant controllers</li>
<li>HA Redundant Cluster-in-a-Box solution with PCIe NTB and GbE heartbeat</li>
