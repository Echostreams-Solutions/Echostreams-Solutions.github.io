<h2>Key Features:</h2>
<ul>
<li>HA Redundant Storage server support two hot-swap MB modules, each with single 2nd Gen AMD EPYC up to 64 cores Single/Multi NUMA domain</li>
<li>4U with 48x 3.5” 12Gb/s dual-ported SAS hot-swap HDD bays</li>
<li>Supports PCIe GEN 4; up to 2TB DDR4 RAM</li>
<li>Support two hot-swap motherboard nodes; each with AMD ROME UP server boards in one system as unified redundant controllers</li>
<li>HA Redundant Cluster-in-a-Box solution with PCIe NTB and GbE heartbeat</li>
</ul>
